## EV(기대값) 판단 (core/ev.py)
매 사이클, 매수 후보(점수 ≥ 문턱)와 보유 종목마다 손절·익절 후 트레일링·보유기간 규칙을 그대로 적용한
경로 시뮬레이션으로 기대수익(비용 차감)을 계산 → 매수 / 대기 / 보유 / 매도.
- 드리프트 = 모멘텀(6개월 평균 × 0.15) + 신호(0.05 × (점수-50)/50 × 확신도 × σ). 우위가 0이면 EV≈0 → 비용 때문에 대기
- 신규: EV ≥ 0%(비용 차감) 이고 승률 ≥ 40% → 매수, 아니면 대기. 보유: EV < −0.5% → 매도
- 주문 로직의 점수만 조정 → 기존 손절·하드캡·이중매도 방지 그대로. 매수를 막거나 매도를 추가만 함
- 화면: 자동매매 → 실행 탭 'EV 판단' 표, 파라미터 탭(on/off·기준), 백테스트 'EV 판단 적용' 비교. 텔레그램 /ev, /status
- 백테스트(23종목, EV 끔 → 켬):

  | 전략 | 2020–2022 | 2023–2026 |
  |---|---|---|
  | momentum_max | +0.4% → +20.0% (샤프 0.08 → 0.56) | +54.9% → +59.0% (MDD −20.6 → −16.2%) |
  | composite | +52.2% → +50.9% (MDD −17.4 → −11.0%) | +123.8% → +80.0% (MDD −21.3 → −18.7%) |
  | momentum | +4.0% → −12.7% | +13.5% → +1.2% |

  효과가 전략마다 다르다 — momentum_max 는 두 구간 모두 개선, composite 는 낙폭↓·상승장 수익↓, 단순 momentum 은 악화.
  라이브 전략(AI 인플루언서)은 과거 판단 데이터가 없어 백테스트 불가 — 모델 가정(IR 0.05)은 보수적으로 잡음.
- 남은 과제: 전략별 점수→수익 보정(과거 데이터로 IR 학습), 단기 과열 시 '더 좋은 진입 대기', 켈리 비중을 사이징에 반영할지 검토
