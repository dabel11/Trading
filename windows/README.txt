============================================================
  AI 트레이딩 — 윈도우에서 실행하기
============================================================

이 폴더(windows\)는 윈도우 PC에서 앱을 켜두고 쓰기 위한 실행 스크립트입니다.
프로그램 본체는 한 단계 위 폴더의 파이썬 파일들(app.py 등)입니다.
→ trade 폴더 전체를 윈도우로 통째로 복사해서 쓰세요.


────────────────────────────────────────────
1) 준비물 (최초 1회)
────────────────────────────────────────────
· Python 3.11 이상
  https://www.python.org/downloads/ 에서 설치
  ★ 설치 첫 화면에서 "Add python.exe to PATH" 체크 필수!


────────────────────────────────────────────
2) 설치 (최초 1회)
────────────────────────────────────────────
windows\setup.bat  을 더블클릭
→ 가상환경(.venv)을 만들고 필요한 패키지를 자동 설치합니다 (수 분).


────────────────────────────────────────────
3) 실행
────────────────────────────────────────────
[A] 앱 전체 (차트 · 백테스트 · 수동/자동매매 UI)
    windows\start_app.bat  을 더블클릭
    → 앱 창(또는 기본 브라우저)이 열립니다.
    → 항상 켜두려면 이 검은 콘솔 창을 닫지 마세요.
    → 자동매매는 앱 안에서 "자동 매매" 토글을 켜면 됩니다.

[B] 자동매매 봇만 (UI 없이 24시간, 가벼움)
    windows\run_bot.bat        (모의 / 안전)
    windows\run_bot_live.bat   (실거래 / 실제 자금 — Alpaca 키 필요)
    → 매일 미국장 개장 후 자동으로 스캔-매매 사이클을 실행합니다.
    → 종료: 콘솔 창에서 Ctrl + C


────────────────────────────────────────────
4) 항상 켜두기 (절전 방지)
────────────────────────────────────────────
윈도우가 잠들면 봇도 멈춥니다. 절전을 꺼두세요:
  설정 → 시스템 → 전원 → 화면/절전 → "안 함(Never)"
  (노트북이면 "전원 연결 시" 기준으로 설정)
화면만 꺼지는 건 괜찮습니다. 시스템 절전만 막으면 됩니다.

· 부팅 시 자동 시작: start_app.bat 바로가기를
  Win+R → shell:startup 폴더에 넣어두면 PC 켤 때 자동 실행됩니다.


────────────────────────────────────────────
5) API 키 (선택)
────────────────────────────────────────────
trade\.env 파일에 키를 넣습니다 (메모장으로 편집):
  FINNHUB_API_KEY=...      (실시간 시세 - 선택)
  ALPACA_API_KEY=...       (실거래 - 선택)
  ALPACA_SECRET_KEY=...
키가 없어도 모의투자·백테스트·시세(yfinance)는 전부 동작합니다.


────────────────────────────────────────────
문제 해결
────────────────────────────────────────────
· "python을 찾을 수 없음" → Python 재설치 시 PATH 체크
· 앱 창이 안 뜨고 브라우저로 열림 → 정상입니다(브라우저 모드)
· 포트 8501 사용 중 → 기존 실행 콘솔을 닫고 다시 시작
· 알림이 안 옴 → 윈도우 알림은 풍선으로 표시. 휴대폰 알림은
  앱 설정 → 알림에서 텔레그램 봇 토큰을 넣으면 어디서나 받습니다.
